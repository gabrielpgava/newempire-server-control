# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-selected Go modular monolith, SQLite, chi, embedded React/TypeScript/Vite frontend, Tailwind, and TanStack Query. Native Linux/systemd is the primary deployment. Node.js is build-time only.

## Users

Administrators of headless Minecraft Java/Fabric servers, including Ubuntu Proxmox LXC deployments. The user confirmed frequent practical administration: status and safety warnings first, dense desktop tables, usable mobile controls, and recovery over visual effects.

## Product Purpose

Manage isolated Minecraft instances through a browser without SSH for routine work. Preserve worlds, unknown content, and external files across imports, backups, runtime changes, and updates.

## Operating Context

Server lifecycle, console, files, worlds, players, Fabric mods, backups, jobs, automation, and independently verified panel updates. Multiple instances and role-based access are required.

## Capabilities and Constraints

The master implementation brief is the required scope, not evidence of completion. No unsupported feature may appear as a functional control. No arbitrary shell or unrestricted root web process. Minecraft EULA acceptance is explicit. World rollback is always separate from content rollback.

## Brand Commitments

New Empire Server Control. English-only, professional, restrained Minecraft-inspired identity without proprietary art or decorative game imagery. PolyForm Shield 1.0.0, source-available. Public repository creation is authorized at gabrielpgava/newempire-server-control.

## Evidence on Hand

The initial repository contained no implementation, screenshots, or test evidence. Generate screenshots only from the implemented application; do not invent operational data or deployment claims.

## Product Principles

1. Data safety before convenience.
2. Truthful readiness, progress, and failure reporting.
3. Least privilege and explicit approval for risky changes.
4. Complete integrated vertical slices, not mock-only controls.

## Accessibility & Inclusion

Keyboard access, visible focus, labeled inputs, readable contrast, accessible status text, responsive tables and dialogs. Respect reduced motion.
