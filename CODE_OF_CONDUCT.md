# Code of conduct

Treat contributors and users with respect. Welcome questions, constructive criticism, and different levels of experience. Discuss code and behavior, not personal characteristics.

Harassment, threats, discriminatory abuse, doxxing, and publication of private data or credentials are unacceptable. Do not distribute malicious worlds, archives, JARs, or exploit code through project discussions.

Report concerns privately to the repository owner through GitHub. Maintainers may edit or remove harmful content, restrict participation, or ban repeat offenders. Enforcement should be proportionate, explain the relevant behavior, and preserve reporter privacy.

This policy applies to repository issues, pull requests, discussions, and other official project spaces.
