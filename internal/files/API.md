# Files domain API (integration boundary)

All paths are slash-separated relative names. `.` means the supplied root. Roots must be opened by the trusted caller, never from a request path. Linux and macOS are supported. The caller owns authorization, secret filtering (especially `server.properties`), durable jobs, exclusive instance locks, stopped-runtime checks, restore confirmation, audit events, and backup policy.

- `files.List(ctx, root, path)`, `Search(ctx, root, path, query, limit)`, `Open(root, path)` (seekable regular-file download), `ReadText(ctx, root, path, maxBytes)`.
- `files.WriteText(ctx, root, path, content, maxBytes)` atomically replaces a bounded UTF-8 text file, preserving existing UID/GID and safe `mode & 0666` permissions; inability to retain ownership fails with the original untouched. New files default to 0600. `Mkdir`, `Move` (never overwrites), `Trash(ctx, root, externalRecoveryRoot, path)` returns a recovery token; `Recover(ctx, root, externalRecoveryRoot, token, destination)` restores that token without overwriting. Recovery must be external and on the same filesystem. Reserved `.nesc-` paths are inaccessible to ordinary file-manager functions.
- `files.ExportZIP(ctx, root, path, writer, progress)` streams an archive; `files.Walk`, `OpenRegular`, `ValidatePath`, `Copy` are shared safe primitives for importer/backups. File links, special files and multiply-linked regular files fail closed.
- `importer.Inspect(ctx, archiveFile, format, limits, progress)` returns all entries with SHA256 hashes and `Preview.Hash`; formats `zip`, `tar.gz` (also `tar.zst` for backups). `Extract(ctx, archiveFile, format, stagingRoot, limits, progress)` requires an empty staging root and recomputes the preview/hash. Compare that hash with the confirmed preview **before** applying staged data. Failure leaves only staging data, never touches an instance. Limits have conservative defaults when zero.
- `backups.Create(ctx, sourceRoot, externalBackupRoot, format, progress)` returns a backup ID and metadata; formats `zip`, `tar.zst`. `List(ctx, backupRoot)`, `Open(backupRoot, id)` (`file, metadata, error`, seekable), `Verify(ctx, backupRoot, id, progress)` (`Manifest, error`) operate on that external root and ID. `StageRestore(ctx, backupRoot, id, parentRoot, progress)` returns `Stage` with `.Name` and `.Manifest`. `CommitRestore(ctx, parentRoot, targetName, stage.Name)` revalidates staging, renames the original to a unique retained recovery directory, then installs staging; it never deletes the original. It returns `RestoreResult` **even on error**, with `.Recovery`, `.Journal`, `.Installed`. Persist these fields. `Recover(ctx, parentRoot, targetName, recoveryName)` explicitly swaps back while retaining the displaced tree, or restores a missing target after an interrupted swap.
- `uploads.New(Config)` returns a service with `Handler()`, `Lookup(ctx, owner, id)` (`Completed, error`; `.File` is already open), `Delete(ctx, owner, id)`, `Prune(ctx)` and `Close()`. Config fields are `Root *os.Root`, `BasePath`, required `Authorize func(*http.Request)(string,error)` returning an owner ID, `MaxSize`, `Quota` (total reserved bytes), `MaxUploads`, and `TTL` (positive, at most seven days). Root is borrowed, must be private (0700), and is process-locked. Mount `Handler()` at **its full BasePath without stripping it**. Own every tus request (including HEAD/DELETE), apply CSRF/Origin in the callback, and never trust metadata for owner or storage paths. Filename metadata is required. Unknown length and concatenation are intentionally unsupported. Call `Prune` periodically; startup and creation also prune expired uploads.

Progress is `files.Progress func(completedBytes int64)`; it reports actual bytes processed, not a percentage. Cancellation interrupts bounded copy loops. An already-open download file must always be closed by its caller. Backup archives contain secrets and must only be served through the privileged backup endpoint, not the ordinary file manager.
